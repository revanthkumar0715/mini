ESP32 IoT Mine Node Hardware & Firmware Reference

Hardware Components

  • Microcontroller: ESP32-WROOM-32 (Dual Core 240MHz, Wi-Fi/Bluetooth)
  • Methane Gas Sensor: MQ-4 Gas Sensor (Analog Pin A0 / GPIO 34)
  • Carbon Monoxide Sensor: MQ-7 Gas Sensor (Analog Pin A1 / GPIO 35)
  • Temperature/Humidity: DHT22 Sensor (Digital GPIO 4)
  • Fall/Motion Sensor: MPU6050 6-Axis Accelerometer (I2C SDA:21, SCL:22)
  • Long Range Comms: SX1276 LoRa Transceiver (868/915MHz SPI)
  • Actuators & Alerts: 5V Relay (Exhaust Fan GPIO 26), Active Piezo Siren (GPIO 27)

System Architecture

The underground node reads analog/digital signals every 1000ms. If gas thresholds or fall acceleration ($>3.5g$) are breached, local relay and siren actuate instantly before broadcasting telemetry via LoRa mesh network to the surface gateway dashboard.
